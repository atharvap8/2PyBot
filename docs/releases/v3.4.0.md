# 2PyBot v3.4.0

This release brings together the Drive improvements from 3.2.0 and 3.3.0,
the guard update, and a shorter, clearer project history.

## What's new

- A dark, full-screen 3D Drive view with shaded CAD, touch navigation and a rear
  chase camera. The map and detailed instruments can be opened when needed.
- Corrected forward movement and tilt. The robot model, trail and depth markers
  now use the same coordinate frame and the bot's existing pitch calibration.
- Direction guides, range arcs and ground cues to make motion easier to see.
  These are visual references, not detected roads.
- Removed the fixed creep limits. Confirmed obstacles still set braking and stop
  limits; fresh missing or partial depth no longer forces crawling.
- ToF range-bias calibration using a measured target, with raw readings retained.
- Robot-model launcher icons, including adaptive and themed variants.
- A revision table with 25 key milestones and a roadmap for camera calibration,
  camera/ToF distance overlays and later ONNX object detection.

## Downloads

- `2PyBot-v3.4.0-debug.apk` is signed and ready to install.
- `2PyBot-v3.4.0-release-unsigned.apk` needs signing before installation.
- Firmware binaries, bootloader, partition table, debug symbols and checksums
  are included in the release assets.

The Android app reports version **3.4.0**, with versionCode **30400**.

## Checks

The release-candidate builds passed 55 Python tests and 18 Android unit tests.
The Drive shaders and assembled model were also checked. The stable tag builds
Android APKs and firmware from the same application code, with the updated docs.

Camera lens and sensor-position calibration are upcoming work. Unknown depth
is still shown as unknown, and the launcher mirror correction remains on the
roadmap.
