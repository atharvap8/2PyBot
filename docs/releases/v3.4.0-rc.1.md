# 2PyBot v3.4.0-rc.1

Release candidate for the consolidated Android Drive, launcher, guard and vision
planning work. This is a **prerelease**, not a final stable release.

## Included changes

- Full-width dark, depth-buffered Android world with shaded current CAD, orbit,
  pan/pinch, centered rear chase camera and collapsible map/details.
- Shared forward-first frame across CAD, odometry, trail, depth and references.
  Display uses the existing PITCHSGN calibration; grounded heading no longer
  retains an idle-compass sideways offset.
- Reference direction ribbon, range arcs and ground parallax cues. These are
  display references, not detected roads or free-space claims.
- Live pose/wheel animation and existing IMU/firmware lift/landing indications.
- Measured-reference ToF range-bias calibration and retained raw/corrected data.
- Removed fixed unknown/partial-depth creep caps. Fresh missing/unconfirmed depth
  leaves normal DRIVEV; measured obstacles still set braking/stop limits, and
  stale/offline depth still holds forward references.
- Assembled robot launcher assets, density variants and Android themed icons.
- Complete four-column revision-history table from repository inception,
  including branch experiments and estimated future feature dates.
- Camera distortion/intrinsic/extrinsic calibration, synchronized ToF overlays,
  replay/evaluation and later ONNX detection/tracking roadmap.

## Downloads

- `2PyBot-v3.4.0-rc.1-debug.apk`: debug-signed, directly installable Android build.
- `2PyBot-v3.4.0-rc.1-release-unsigned.apk`: release build requiring signing.
- Firmware binaries, bootloader/partition/debug outputs and checksum manifests
  are attached by the tagged workflows.

The APK reports `3.4.0-rc.1`; its numeric versionCode is based on `3.4.0`.

## Validation and candidate follow-ups

- Local Python suite: 55 tests passed.
- Android unit suite: 18 tests passed; debug and unsigned release builds checked.
- GLSL compile/link and actual assembled-mesh rendering checked.
- Physical forward/tilt, touch navigation and actual obstacle behaviour remain
  candidate validation tasks. Unknown depth is not confirmed clear space.
- Launcher mirror correction remains on the backlog. Camera intrinsic/extrinsic
  and camera/ToF geometry calibration are planned, not completed in this RC.
