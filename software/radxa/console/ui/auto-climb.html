Mode selection

These controls select the controller policy. Arming still requires local gamepad START. D-pad DOWN selects manual climb or manual normal; press Enable auto here to return to automatic detection. Manual policy persists across stop/rearm; reboot returns to auto enabled.

How to read the detector

SUSPECT: steady request and sustained load cues. CLIMB: uphill/deficit assistance. DOWNCLIMB: inferred descent/braking assistance, with speed-reference regulation. EXITING: monitored hand-back; compensation is restored if tracking or overspeed worsens. COOLDOWN: a short re-entry delay. LIMITED: poor wheel following or no progress, not a temperature measurement. MANUAL: D-pad/H override. Brief stops on a slope retain compensation; quiet flat neutral release takes roughly 6–8 s.

The descent limit is a governed reference, not a hard clamp on wheel motion. Watch actual encoder speed and excess speed. Balance catches keep full wheel authority. Mild 25% recovery no longer drains the C integral. IDLE values can retain the last controller evaluation.
