Lidar … Robot … Mode …

1Check the lidar

The lidar spins and measures distances all around. You should see the room's outline on the right.

  • Lidar connected
  • Lidar health is good
  • About 20 scans per second

2Check the wheels

SLAM uses the wheels and the gyro to guess how far the robot moved. Two quick tests prove they're right. The robot can be off: just push it by hand.

  • Robot data is arriving
  • Gyro figured out ("spin the robot a few times")
Push it 1 m straight ahead.
Turn it left about 90°.

3Make a map

Press start, then drive around slowly with the gamepad. The map grows as you go. Finish by driving back to where you started: that lets SLAM line everything up.

Tips: walk-speed or slower · avoid big empty spaces · don't lift the robot while mapping.

4Save it

Give the map a short name like living_room.

5Use a saved map

Load a map, put the robot where you started mapping, and it will show where it is. Lost? Press Find me.

6Correct or extend a map

Extend loads the selected map, finds the robot on it, then keeps mapping on top: new rooms are added and changed areas redrawn. Erase forgets a spot (moved furniture, ghost walls) so mapping draws it again. Save when done.

7Name areas

Choose Label tool, tap a spot on the map and type a name like kitchen. Labels are saved with the map and can be used as destinations.

    8Drive by itself

    Press local START, keep the gamepad connected and this page open. Moving a stick takes over at once; STOP disarms.

    What do these words mean?
    Scan
    One full spin of the lidar: hundreds of distance dots around the robot.
    Odometry
    The robot's own guess of how it moved, from wheel turns and the gyro. It slowly drifts.
    Pose
    Where the robot is (x, y) and which way it faces.
    Occupancy grid
    The map: a grid of 5 cm squares, each white (free), black (wall) or grey (unknown).
    Scan matching
    Sliding the new scan over the map until it fits. This corrects the drift.
    Loop closure
    Coming back to a place you've already mapped, so the map lines up again.
    Localization
    Using a saved map to find where the robot is, without changing the map.
    Advanced

    Change these with environment variables or slam/engine.py DEFAULTS.
